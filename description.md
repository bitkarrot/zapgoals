Create and share Lightning funding goals with live progress updates.

ZapGoals provides:

- Public, customizable goal pages with target amounts and dates
- Flexible contribution options and LNURL-pay support
- Optional Lightning Addresses for individual goals
- NIP-57 zap request handling for Nostr-aware contributions
- Realtime progress updates as tagged contribution invoices settle

Goal progress is isolated from unrelated wallet activity, making ZapGoals suitable for campaigns, projects, events, and community fundraising.
